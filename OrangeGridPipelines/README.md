## Working pipelines for Syracuse University's OrangeGrid HTC 

### Purpose 
This directory contains multiple working examples of setting up pipelines on OrangeGrid.  Examples include: 

    1. CALVADOS: multidomain protein simulations. Submitted jobs are read in from a multicolumn text file, allowing the user to specify what needs to be rerun 
    2. batch_nardini: Sequence features for many IDRs. Submitted jobs are read in from a single column text file
    3. esm_embed: embed sequences using ESM2.  Submitted jobs are read in from a directory containing all sequences intended to be embedded.
